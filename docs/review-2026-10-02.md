## P2: One invalid provider discards the saved catalog

Location: `src/core/maps.cpp:106`, with persistence through `src/app/window.cpp:338`.

`MapSources::restorePreferences` rejects the entire catalog when one known provider fails validation. The object retains its default providers. The next save replaces the saved sources with those defaults. This silently removes unrelated custom providers from a valid JSON profile.

The probe stored one valid custom XYZ provider and one invalid WMS endpoint. It opened a window and called `savePreferences`. The saved file no longer contained the valid custom provider. A returning plugin can also expose previously unrecognized invalid values to this path.

Retain invalid entries as disabled data. Report their errors without discarding unrelated sources. Add a restart test with both valid and invalid sources. Include an absent plugin that returns with stricter validation.

## P2: Provider forms report success after a save failure

Locations: `src/app/map_manager.cpp:65` and `src/app/map_manager.cpp:124`.

Add and Edit supply a save callback that always returns an empty error. Their apply callbacks also discard the result from `MapSources::put`. The host attempts persistence through a separate signal connection. Its failure does not reach the form.

The probe opened an invalid profile that the application correctly protected from writes. It edited a provider and pressed Apply. The form reported `Configuration saved.` while the host reported `The preferences file is invalid. It will not be overwritten.`

Pass the actual apply and persistence results to the form. Keep the form open after a failure and explain that changes remain session-only. Add provider-form tests for locked profiles, invalid profiles, and failed writes.

## P2: Coordinates sort as text

Locations: `src/core/store.cpp:25` and `src/plugins/tracks.cpp:152`.

The event model returns formatted coordinate strings for display. The table proxy also uses those strings for sorting. Ascending latitude therefore places 10 before 2. Longitude has the same defect.

The probe inserted latitudes 2 and 10, then sorted the actual CoT Events table in ascending order. The result was `10.00000, 2.00000`.

Provide numeric values through a separate sort role. Keep localized strings for display. Add tests for positive coordinates, negative coordinates, decimal values, and locale changes. Preserve the selected identity during each sort.

The review inspected QObject ownership, callback contexts, cancellation, shutdown, file descriptors, preference locks, and shared logging state. The new sanitizer run reported no application memory fault. This result does not establish that every code path is safe.

Recoverable errors use return values or shared diagnostics. Fatal Qt errors and memory corruption still terminate the process. The application cannot promise recovery from every fault in Qt, native plugins, or graphics drivers.
